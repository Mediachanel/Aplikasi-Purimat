Teknologi sistem
20
01
Apa teknologi tampilan yang digunakan?
HTML, CSS, dan JavaScript responsif; versi Android membuka portal yang sama melalui WebView.
02
Apa teknologi server dan database?
Node.js, Express dan TypeScript sebagai API; PostgreSQL menyimpan data dan transaksi.

Perlindungan KK dan KTP
31
01
Siapa bisa membuka dokumen identitas?
Pemilik dan ketua; sekretaris untuk dokumen yang terkait pengelolaan atau pengajuan. Bendahara tidak membuka KTP/KK rumah lain.
02
Di mana file disimpan?
Lampiran privat disimpan di volume server, bukan direktori publik; akses melalui API dan tiket singkat.
03
Apakah file terenkripsi saat tersimpan?
Enkripsi khusus file atau database saat tersimpan belum dikonfirmasi. Jangan mengklaim enkripsi at-rest sudah tersedia.

TANYA JAWAB · INFRASTRUKTUR
Keamanan server
32
01
Bagaimana layanan dibatasi?
API berjalan sebagai pengguna non-root, filesystem aplikasi read-only, tanpa Linux capabilities dan dengan volume lampiran terpisah.
02
Bagaimana rahasia server disimpan?
Kunci JWT dan password database dipisahkan dalam konfigurasi privat; jangan ditaruh di slide atau repositori.
03
Bagaimana menjaga browser dari serangan umum?
Ada pembatasan origin lintas situs, CSP, anti-framing, no-sniff dan kebijakan referrer.

Keterbatasan dan pemulihan
33
01
Apakah sistem kebal serangan?
Tidak. Hardening dan pengujian internal mengurangi risiko; audit independen dan pemeliharaan tetap diperlukan.
02
Bagaimana bila server atau internet mati?
Aplikasi memerlukan koneksi dan server; belum tersedia mode offline. Siapkan prosedur pencatatan sementara.
03
Bagaimana cadangan dan pemulihan?
Cadangan database pernah dibuat; jadwal otomatis, salinan terpisah dan uji pemulihan berkala perlu ditetapkan.
